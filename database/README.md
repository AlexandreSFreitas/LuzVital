# Database Design — LuzVital

Modelo: `docs/DATABASE_MODEL.md` (9 tabelas, 3FN). Padrão: nomes sem prefixo, PK `GENERATED BY DEFAULT AS IDENTITY`.

| Arquivo | Conteúdo |
|---|---|
| `ddl.sql` | CREATE TABLE (PK, NOT NULL, CHECK, UNIQUE) + ALTER TABLE (9 FKs) + comentários |
| `dml.sql` | Dados **fictícios**, ≥ 5 linhas por tabela, `COMMIT` e ajuste das IDENTITY |
| `dql.sql` | As 3 consultas da rubrica |
| `luzvital_logico.png` | Diagrama relacional exportado do Oracle Data Modeler (13/11) |
| `luzvital.dmd` + `luzvital/` | Projeto do Data Modeler (para editar o diagrama) |

## 1. Rodar os scripts (SQL Developer, servidor Oracle da FIAP)

1. Conecte com o seu usuário da FIAP.
2. Abra `ddl.sql` e execute como script (**F5**, não Ctrl+Enter). Deve terminar sem erro.
   - Para recriar do zero, descomente o bloco de `DROP` no início (apaga tudo).
3. Abra `dml.sql` e execute com **F5**.
4. Abra `dql.sql` e execute cada consulta. Conferência esperada:
   - Consulta 1: 6 pacientes com a região.
   - Consulta 2: 7 linhas (interrupções 1, 2, 3 e 5, agrupadas por status do alerta).
   - Consulta 3: 11 linhas; **Rosa Menezes Cardoso** aparece com as colunas do alerta vazias.
5. Conferir contagem:

```sql
SELECT 'regiao' t, COUNT(*) FROM regiao UNION ALL
SELECT 'paciente', COUNT(*) FROM paciente UNION ALL
SELECT 'equipamento', COUNT(*) FROM equipamento UNION ALL
SELECT 'paciente_equipamento', COUNT(*) FROM paciente_equipamento UNION ALL
SELECT 'contato', COUNT(*) FROM contato UNION ALL
SELECT 'paciente_contato', COUNT(*) FROM paciente_contato UNION ALL
SELECT 'interrupcao', COUNT(*) FROM interrupcao UNION ALL
SELECT 'alerta', COUNT(*) FROM alerta UNION ALL
SELECT 'acao_apoio', COUNT(*) FROM acao_apoio;
```

## 2. Diagrama lógico no Oracle Data Modeler

Caminho mais rápido: importar o `ddl.sql` (o diagrama sai idêntico ao script).

1. **File → Import → DDL File…** e selecione `database/ddl.sql`.
2. Em *Database*, escolha **Oracle Database 12c** (ou superior) → **Next** → marque todas as tabelas → **Next** → **Merge**.
3. Feche o relatório de importação. O **Relational Model** abre com as 9 tabelas e as 9 FKs.
4. Organize: botão direito no fundo → **Auto Layout** (depois ajuste à mão: `REGIAO` em cima, `ALERTA` no centro).
5. Mostre as cardinalidades: **View → Notation** (ou botão direito → *Notation*) → **Bachman** ou **Information Engineering** (pé de galinha). Confira que cada FK aparece como relacionamento 1:N.
6. (Opcional, mas recomendado) **Engineer to Logical Model** (botão `<<` na barra) para ter também o modelo lógico com entidades e relacionamentos nomeados.
7. Exporte a imagem: **File → Data Modeler → Print Diagram → To Image File** → salve como `database/luzvital_logico.png`.
8. Salve o projeto do Data Modeler (`luzvital.dmd` + pasta `luzvital/`) em `database/`.

Checklist do diagrama (rubrica, 20 pts): tabelas, atributos com tipo, PKs, FKs, relacionamentos e cardinalidades visíveis. **Não** usar link de diagrama em nuvem.
